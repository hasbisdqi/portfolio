## 1. Tantangan & Kebutuhan Sistem

- **Tantangan 1**: Mengurangi response time API di bawah 100ms dengan beban request concurent tinggi.
- **Tantangan 2**: Mengimplementasikan micro-interactions 60fps tanpa menyebabkan layout shift pada rendering browser.
- **Tantangan 3**: Menjaga isolasi lingkungan container database dan zero downtime deployment.

## 2. Keputusan Desain & Arsitektur Teknis

Jelaskan alasan pemilihan teknologi dan bagaimana arsitektur data dirancang:

```typescript
// Contoh implementasi service cache layer
export async function getCachedProjectData(projectId: string) {
    const cacheKey = `project:data:${projectId}`;
    const cached = await redis.get(cacheKey);
    if (cached) return JSON.parse(cached);

    const freshData = await db.query.projects.findFirst({
        where: eq(projects.id, projectId),
        with: { dependencies: true, metrics: true }
    });

    await redis.set(cacheKey, JSON.stringify(freshData), { ex: 3600 });
    return freshData;
}
```
